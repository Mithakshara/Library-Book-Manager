# Library Book Manager (Java)

A simple console application for managing a small library, built as a
practice project while learning Java. Users can add books, search for
them, and borrow or return them through a text menu.

## Features

- Add a new book (ID, title, price)
- Display all books
- Search for a book by ID
- Borrow a book
- Return a book
- Input handling for invalid menu choices

## Concepts Used

- Object-Oriented Programming: classes, objects, constructors,
  `this`, `private` fields, getters and setters (encapsulation)
- `ArrayList<Book>` with `add()`, `get()`, and `size()`
- Searching a list of objects and returning one object (or `null`)
- Static methods with parameters and return values
- `Scanner` for user input
- `while (true)` loop with `break` for the menu
- `if / else if / else` conditions
